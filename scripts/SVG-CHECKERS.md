# studymate-svg-checkers

**StudyMate 课件的 SVG 几何自检工具**。讲课件里手写的 `::: svg` 示意图最容易犯的三类错误，
都是"数值上必然错、但肉眼极易滑过"的，本工具把它们交给脚本判。

## 为什么需要它

这门课在《揭开算法分析的帘子》一课上，因为手写 SVG 示意图连踩四轮错误：
口径三套并存、凭空多出一个 `2n`、曲线方向画反、`2^n` 的冲出点标错。
其中两类（文字越界、文字互相压住）反复出现，靠"交付前打开图看一眼"没能拦住——
单看一张图，它像一条光滑的下降曲线，配上坐标轴毫不违和。

**结论（也是本工具的设计前提）**：形状与文字的一致性、以及版式的边界，必须由脚本判。

## 用法

```bash
# 几何自检：文本越界 / 文本重叠 / 线段方向
python3 check_lesson_svg.py <课件内容文件 .md>

# 预览：把每个 ::: svg 块按源坐标重画成 PNG，用来"真的看一眼"
python3 preview_lesson_svg.py <课件内容文件 .md> [输出目录] [--only N] [--scale N]
```

退出码：`0` = 合格；`1` = 有问题（逐条打印 `<文件>:<行号> <问题>`）；`2` = 用法或字体错误。

依赖：Python 标准库 + Pillow（PIL）。不需要浏览器、不需要 cairosvg/svglib/rsvg-convert。

## check_lesson_svg.py 判什么

| # | 判据 | 说明 |
|---|---|---|
| ① | **文本越界** | 按真实字体度量算每个 `<text>` 的包围盒，左右端须在 `[0, viewBox 宽]`、下缘须 ≤ `viewBox 高`。**`text-anchor="end"` 与 `"middle"` 的标签必须查左端**——锚点在右侧或中间的中文长句会整串向左伸，只查右端必漏。 |
| ② | **文本重叠** | 同一块内任意两个文本包围盒不得相交。 |
| ③ | **线段方向** | 横向跨度 > 60 的线若 `dy > 0`（SVG 的 y 轴朝下，屏幕上是"向右下"），在"随 n 上升"这类图里就是画反了。纵向短线下探、横线、轴标线都不在此列。 |

## 已知盲区（**这些是真踩过的，别在别处当成"检查过了"**）

1. **字体前提**：测宽必须显式加载含中文字形的字体（微软雅黑 `msyh.ttc`）。
   若让 PIL 落到不含汉字的回退字体，中文串会被量短——**实测差 24%**
   （中文长句在 CJK 字体下宽 211、在 Arial 下宽 161），于是
   `text-anchor="end"` 的标签左端跑到 `x = -83` 也不会被发现。
   本脚本启动时用「一个汉字 ÷ 一个拉丁字母」的宽度比断言字体确实含汉字，
   **不满足直接退出 2**，绝不"用回退字体凑合量"。
2. **线 × 文本相交不查**：只比较"文本 × 文本"的包围盒，
   **查不出引导线/虚线穿过文字**。真实发生过一次：一条延长后的指针引导线从「格」字上切过去，
   两个 checker 都没报。
3. **只认四种元素**：`<text>` / `<line>` / `<rect>` / `<circle>`。
   `<path>`、`<g transform=…>`、行内 marker 箭头等一律忽略，
   因此图里若有路径或变换，判定结果与浏览器实际样子会有出入。

## preview_lesson_svg.py 的额外注意

它是**近似重画**，不是完整 SVG 渲染：已知它对 `fill="none"` 的处理与浏览器一致
（只描边不填色），但个别情况下边框、`<g>` 继承属性仍可能与浏览器有差异。
它的用途是"看图找观感问题"，**判定几何请以 `check_lesson_svg.py` 为准**。

## 建议的接入方式

在渲染器（`scripts/render_lesson.py`）或课件检查器（`scripts/check_lesson.py`）之后串一条：

```bash
python3 check_lesson_svg.py <科目>/lessons/<序号>-<节点id>.md || exit 1
```

它与现有两个检查器职责不重叠：`render_lesson.py --check` 管内容格式，
`check_lesson.py` 管渲染产物的页面级约束，本脚本管**手写 SVG 的几何**。
